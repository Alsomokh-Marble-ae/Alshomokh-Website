AL SHOMOKH MARBLE WEBSITE

Files:
- index.html: Home
- about.html: About Us
- products.html: Marble Types / Collection
- services.html: Services
- projects.html: Projects / inspiration gallery
- contact.html: Contact
- assets/style.css: design and responsive layout
- assets/script.js: Arabic/English language switch
- assets/favicon.svg: temporary text favicon

HOW TO USE:
1. Extract the ZIP file.
2. Upload the contents of the extracted folder to your Netlify site (or replace the existing site files in your deployment source).
3. Make sure index.html is in the root folder, not inside an extra nested folder.
4. Test the site on desktop and mobile.
5. The logo is currently a temporary letter mark. Replace it with the company's real logo later.
6. Images are remote illustrative Unsplash images and need an internet connection.
7. Contact details retained exactly: 0542422822 / alshomokh.marble@gmail.com
